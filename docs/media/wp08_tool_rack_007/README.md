# Actual Native rack keyframes

[Four full-frame Global RGB captures](actual_keyframes.png) show release,
open-hand withdrawal, closure on the measured resting tool and the final
reacquired hold. Original timestamps are printed above each image. No solver,
renderer, image generator, crop or geometric reconstruction created these
panels. [Provenance](provenance.json) includes original NPZ and RGB-array hashes.

The episode is the optional Native rigid-only rack007 skill. It performs no
material cutting and does not establish Lab pickup parity or calibrated D455
hardware behavior. The separate raw contact/state audit is documented in
[independent physical-tool validation](../../PHYSICAL_TOOL_INDEPENDENT_VALIDATION.md).
